# Character Anchor System

The anchor is the identity contract. Keep it compact and repeat it in every prompt that should preserve the same person.

## Anchor fields

- Codename / name
- Exact age when supplied
- Gender presentation
- Historical/social identity
- Economic condition
- Face shape and jaw/chin
- Brows
- Eyes and spacing
- Nose
- Mouth
- Skin and age markers
- Hair silhouette
- Headwear
- Build and posture
- Signature clothing silhouette
- Fabric/material
- Main palette
- Signature accessory / prop
- Classic Chinese hand-drawn animation visual target

## Immutable template

```text
CHARACTER ANCHOR:
[name], [age], [identity], [class/economic condition], [face shape], [brows],
[eyes/spacing], [nose], [mouth], [skin/age markers], [hair], [headwear],
[build], [posture], [signature costume], [fabric], [palette], [accessory],
[classic Chinese hand-drawn 2D cel-animation visual language]
```

## Variable template

```text
OUTPUT VARIABLE:
[expression], [pose], [allowed clothing change], [camera], [background],
[layout], [lighting], [output format]
```

## Never drift casually

- face silhouette
- eye spacing
- brow design
- nose
- mouth
- age
- hair silhouette
- headwear
- body proportions
- signature costume silhouette
- main palette

## Consistency escalation

1. Text anchor for exploration.
2. Approved reference sheet.
3. Reference-image/edit workflow for controlled changes.
4. Reuse approved stills for image-to-video.
5. Maintain a project cast registry for recurring characters.

## Cast registry

```text
CAST REGISTRY
- Character A: [compact anchor]
- Character B: [compact anchor]
- Character C: [compact anchor]
```

Before creating a new major character, compare against the registry and create at least five meaningful visual differences from the closest character.
