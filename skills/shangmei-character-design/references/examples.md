# Examples

## Example A — 45-year-old grain-shop owner

```text
CHARACTER ANCHOR:
Hu Shun, 45-year-old male grain-shop owner in an ancient Chinese market town,
ordinary prosperous small merchant, short broad face with slightly softened cheeks,
thin long brows, narrow observant dark eyes, moderate eye bags, rounded nose tip,
thin compressed lips, mature nasolabial area, black hair tied neatly and mostly
covered by a dark-brown traditional shopkeeper cloth cap, mildly stocky build with
slightly relaxed shoulders from years behind a counter, dark gray-brown cotton-linen
long shirt under a muted brown short outer jacket, plain cloth belt, dark trousers,
black cloth shoes, restrained dark-brown / smoke-gray palette, classic Chinese
hand-drawn 2D cel-animation visual language, rounded inked contours, low-saturation
traditional colors, vintage paper-and-cel feeling
```

Default sheet variable:

```text
16:9 horizontal, pure white background. Left: large front-facing head-and-shoulders
portrait clearly showing age, face construction and merchant cap. Right: front / side
/ back full-body views of the same person. Front lightly folds arms; side touches chin
as if calculating; back relaxed. Same face, same age, same cap, same costume and same
body proportions in every view. No text, no watermark, no extra characters.
```

## Example C — make the same character older

```text
Keep the approved character's face silhouette, eye spacing, nose, mouth, hairstyle
family, body identity and clothing exactly recognizable. Change age from 38 to 52.
Add moderate upper-lid heaviness, slight eye bags, deeper nasolabial structure,
slightly softer cheeks and jaw, a few gray strands, subtler forward posture and older
hands. Do not redesign the face. Do not change clothing color. Do not create a new
person.
```

## Example D — anti-same-face comparison

Existing character:
- long face
- thick arched brows
- narrow eyes
- high narrow nose
- thin lips
- tall thin build
- gray-blue clothing

New merchant should intentionally use:
- short broad face
- thin straighter brows
- wider eye spacing
- rounded nose tip
- firmer small mouth
- mildly stocky build
- dark brown / smoke gray clothing

Difference must exist in structure, not only palette.
