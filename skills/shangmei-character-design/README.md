# shangmei-character-design

A character-design skill for original characters inspired by classic Chinese hand-drawn animation aesthetics.

## What it adds

- Character Anchor identity locking
- believable age design
- occupation-driven face, body and wardrobe logic
- anti-same-face comparison for multi-character projects
- classic Chinese 2D cel-animation visual direction
- default 16:9 white-background production sheet
- left: large front-facing portrait
- right: front / side / back full-body turnaround
- expression sheets
- outfit-only edits
- headwear-only edits
- older / younger variants
- compact video continuity anchors for image-to-video workflows

## Typical inputs

```text
45岁古代粮铺老板，精明，小气，戴掌柜帽。
```

or

```text
58岁农夫，老实，常年干农活，不要和已有男角色撞脸。
```

## Useful intents

`/character` `/sheet` `/turnaround` `/expressions` `/older` `/younger` `/outfit` `/hat` `/variant` `/lock` `/compare` `/video-anchor`

Slash syntax is optional; natural Chinese requests work as well.

## Design principle

The target is not to copy a specific existing animation character. The skill uses the visual language of classic Chinese hand-drawn 2D animation to create new, independent character identities suitable for production continuity.
